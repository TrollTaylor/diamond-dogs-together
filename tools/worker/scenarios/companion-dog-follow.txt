# D7 (docs/vehicles-companions-design.md 6.12, 8.9): the guest's copy of the host's D-Dog follows the host dog's state,
# and the M2 legs (walk 3 m, run 5 m) on the shipped hold with the guard armed. The host's own dog is hurt, put to
# sleep, woken and killed by the host-only lab levers (companion_lab dog_life / dog_stun: the native record of the
# host's dog); the guest's copy follows through the host's dog-state byte (COMPANION_POSE state) and its native guard.
# Then the host's re-call (companion_lab recall: the dead DOG bit cleared, the dog called 5 m in front). Also the
# restore fallback filmed with the dog in view (companion_lab kill_mirror while the host's dog lives).
#   pwsh -File tools/worker/Invoke-WorkerScenario.ps1 -ScenarioPath tools/worker/scenarios/companion-dog-follow.txt
#        -PartnerProfile native -NativeStage gun -BuildProfile research -HostSaveSeed afgh-ledge -GuestSaveSeed afgh-horse
# Expected: legs track windows within=1 (walk 3 m, run 5 m) and frames fol-walk / fol-run with the dog on both screens;
# hurt host step=state byte=138 -> guest dog_guard=follow byte=0x8a life ...>3226; asleep host state=1 -> guest stun ..>0,
# dog_state state=1, frames fol-asleep; awake state=0 on both; down host companion_hurt Dead -> guest follow byte=0xc0
# kill=1, guest companion_hurt Dead, dog_restore step=dead host=down (no send-away), frames fol-down (both dogs down);
# re-call: guest step=recalled, kdog on both, frames fol-recall.
