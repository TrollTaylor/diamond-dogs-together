# arrival-prevent watchdog proof (docs/world-sync-design.md 9.2): lab probe guest_frozen_heli makes the guest keep the
# host's start position seeds once more (the 0.14.5 behaviour), and the host's sortie into Mother Base stores the friend's
# helicopter start position (goto_lz=1), so the guest's arrival helicopter freezes as in the friend's log. The watchdog
# (lua/coop/world_arrival.lua) must run the way out by itself within about 25 s: step=unstick; why=static_heli, a local
# restart, on foot at Command (step=mb_foot; at=restart), and both players see each other.
