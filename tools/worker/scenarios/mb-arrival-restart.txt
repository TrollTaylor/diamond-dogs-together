# (act 102), presses the pause-menu Restart: the lab probe guest_restart sends the engine's own UI PauseMenuRestart
# message through TppMission.OnMessage, so it passes world_follow's guest suppression and the way out (lab only).
#   run-hidden.ps1 -Scenario tools/worker/scenarios/mb-arrival-restart.txt -ExtraJoined '-Mode lab -WanSim bad
#       -PartnerProfile native -NativeStage gun -BuildProfile research -SaveSeed real -TimeoutSec 600'
