# Expected (sliced script-observer logs of both copies + the frames named below; the Lua lines are written
# event=supply;step=... and appear in the log as world_lua=event=supply; step=...; the native ones as supply=...):
#   0) both: supply=installed;detours=2;observe_only=1 and world_lua=event=supply; step=on.
#   1) the host's script drop (F9 row "supply drop x y z": Player.RequestToSupplyCbox, an AMMO box) aimed at the guest:
#      host step=drop_local; origin=1; oseq=1; ... sent=1; guest step=mirror; origin=1; oseq=1; ok=1 and
#      supply=request;...;mirror=1 with the host's x/y/z, the toast (note 21 a=1); the landing marker on both screens.
#   2) it lands on the guest: state 8 then 14 on both copies, then step=delivered; origin=1; oseq=1 on both (nothing
#      sent, no "partner took" toast). Frames b-*: the guest's screen "Surplus Supplies Retrieved" or more ammo [U: the
#      script AMMO box carries equip 0], the host's screen no notice (the contents went to the guest only).
#   3) the host's own iDroid AMMO / FULTON drop (Tab, 3 MISSIONS, Enter SUPPLY DROP, Enter AMMO / FULTON, Space OK) on
#      the host: the same sync; the host's screen "Surplus Supplies Retrieved", the guest's (3 m away) none.
#   4) the guest's own iDroid drop: the same with the roles swapped (origin=2).
#   5) crossing drops (review r1101: one box per copy, so a mirror would reset the receiver's own paid box): the host's
#      and the guest's script drops one step apart, each at its own spot (3 m apart, beyond the 1 m echo guard). The
#      host keeps its own box: step=mirror_held; origin=2; oseq=2 (no request, no toast); the guest's own box is sent
#      (step=drop_local; origin=2; oseq=2; ...; sent=1) and kept (it either held the host's drop or its own request
#      replaced the mirror). Each box ends step=delivered on its own copy; no remove, no "partner took" toast.
#   6) the host's iDroid WEAPONS / ITEMS drop [U] (run 5acbcb83: Enter on WEAPONS / ITEMS opens "Select weapons." with
#      the equipped WU S.PISTOL first; Enter + Space there ordered nothing): S to the next pistol, Enter to select it,
#      Space (OK), then Space (OK) on the map. Not a synced type (only AMMO / FULTON 0:431 and the script AMMO 4:0):
#      step=drop_local; origin=1; oseq=4; ...; sync=0 on the host, nothing on the guest. Then the host takes it (E at
#      the box, which lands at the host's own spot): step=pickup; ...; cur=1.4 and step=gone_local; ...; why=pickup;
#      sent=0 (H3: the stock OnPickUpSupplyCbox on the taker's copy, the evidence a later synced type needs). The
#      remove path (kind 2, the lever, note 21 a=2) has no synced type that reaches it in normal play: [U], not shown.
