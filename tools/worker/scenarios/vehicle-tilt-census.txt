# WS3 step 0 (docs/vehicle-ws3.md): the read-only vehicle census. Nothing is
# written: partner_ride_census=1 only logs, once a second per ridden vehicle,
# the unit record (rec+0x20 pose, +0x2C yaw, +0x44/+0x48 the other two Euler
# angles, +0x6C type, +0x6E realized, +0x6F slot) and its realized slot body
# (cat+0x1C8)[slot] with same=1 when the body IS the record (critic #16).
# The host drives the nearest authored jeep away from the Wakh Sind plaza over
# the surrounding slopes while the guest watches (the seat scenario's steps).
#
# Run (both copies on the same build, -PartnerProfile native for the seat key):
#   pwsh -File tools/worker/Invoke-WorkerScenario.ps1 -ScenarioPath tools/worker/scenarios/vehicle-tilt-census.txt
#        -PartnerProfile native -NativeStage gun -SaveSeed lab
#
# Evidence (host log: who=local is the driver's own record; guest log:
# who=remote is the guest's copy of that vehicle):
#   partner_ride_census; who=local; id=256xx; ref=ok; type=0x..; cat=..; ...; realized=..; ...; a44_mrad=..; a48_mrad=..;
#     body_ref=ok; ...; same=1|0
#   - A1 may be enabled only if same=1 on both sides (the realized body is the record).
#   - The driver's a44_mrad / a48_mrad must CHANGE while it climbs and turns (live pitch/roll in
#     the record) and stay small on flat ground; the guest's who=remote angles stay level
#     (today's bug: only position and yaw cross the wire).
#   - cat= is the same on both sides for an authored jeep (the B1 category gate).
