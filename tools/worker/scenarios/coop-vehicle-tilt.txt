# WS3 A1 (docs/vehicle-ws3.md): the driven vehicle tilts with the ground on
# the viewer. RUN ONLY AFTER vehicle-tilt-census.txt showed same=1 on both
# sides and live driver angles. With partner_ride_tilt=1 on both copies each
# side's ride addendum advertises RIDE_TILT; the driver reads its own record
# +0x44/+0x48 (partner_ride_tilt=read) and sends them under the RIDE_FAST
# tick; the viewer interpolates them and writes its copy's record right before
# each SetPosition (partner_ride_tilt=write), so 0xBA9710's per-frame move and
# the seat anchor both pick them up. An authored jeep (no seat-by-id needed).
#
# Run: pwsh -File tools/worker/Invoke-WorkerScenario.ps1 -ScenarioPath tools/worker/scenarios/coop-vehicle-tilt.txt
#      -PartnerProfile native -NativeStage gun -SaveSeed lab

# Expected: host partner_ride=ext_rx; ...; features=0x02 (and the guest too);
#   host partner_ride_tilt=read; id=256xx; a44_mrad=..; a48_mrad=..; n=..
#   guest partner_ride_tilt=write; id=256xx; a44_mrad=..; a48_mrad=..; before=..; n=..
#   guest world log event=ride_fast; ...; tilt_written=<growing>; host ...; tilt_sent=<growing>
#   guest census who=remote a44/a48 now follow the host's who=local values (100 ms behind)
#   no partner_ride_tilt=refused; reason=identity (that means the census was not same=1)
