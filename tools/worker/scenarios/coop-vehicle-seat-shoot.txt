# M7 (docs/vehicles-companions-design.md section 9 M7, 6.7; docs/native-puppet.md "Seat gun"): shooting as a passenger.
# Part A: the host drives the africa-jeep (veh_lv_0000 = 25608), the guest rides back seat 2 and kills a guard while
# the host drives; the driver's copy shows the partner's raised gun in the seat (partner_seat_gun: GunHoldStart ->
# GunHold on the DM-seated body 1, its aim rates from the guest's seated v6 direction). Part B: the roles reversed (the
# guest drives, the host shoots from back seat 2).
# The target, relative to the jeep wherever it stands: goto_vehicle jeep puts a player 1.9 m out on the driver's side
# facing the jeep; forward 7 carries the host through to 5.1 m out on the passenger side, facing away; spawn_enemy here
# warps a guard 5 m further (debug_soldier_warp=1, notice restricted); enemy sleep nearest puts him to sleep so he does
# not walk off (host commit, the guest applies). The passenger boards from the driver's side (back seat 2), its camera
# still facing the passenger side; the lever enemy_aim_nearest 0.3 turns its camera to the sleeping guard (Player.
# RequestToSetCameraRotation) before and during each burst, while the driver reverses.
# Expected (lab): guest partner_seat_gun=configured; key=1 / host the same; guest aim_dir=valid; reason=seat while it
# aims seated (never reason=convention); host partner_seat_gun=hold; seq=..; vehicle=25608; seat=2 -> partner_gesture=
# submit; ...; kind=gun_start -> applied; ok=1 -> submit; kind=gun_hold -> partner_seat_gun=rates; ok=1 -> release ->
# partner_gesture=ended; via=end; cause=release; null=1. The kill: guest world_lua=event=req; rid=..; ent=.., host
# world_lua=event=commit; ent=..; actor=guest; (Part B: host event=commit; ...; actor=host; guest event=apply).
# Frames (look at them): m7-seat-aim (the passenger's own view, gun raised), m7-partner-gun (the driver's view of the
# partner's raised gun in the seat), m7-fire-*, m7-after; the same with m7-rev-* for Part B.
# Run (hidden worker, coordinator only, under the verify lock, MGS_GAME_LUA_DIR unset):
#   pwsh -File tools/worker/Invoke-WorkerScenario.ps1 -ScenarioPath tools/worker/scenarios/coop-vehicle-seat-shoot.txt
#        -PartnerProfile native -NativeStage gun -BuildProfile research -SaveSeed africa-jeep

heldcapture guest guest rmb m7-seat-aim 2
