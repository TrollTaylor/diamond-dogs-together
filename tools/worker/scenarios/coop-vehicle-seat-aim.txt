# should reach the stock gun hold (upper act 2, gun mode 7) and fire (modes 9/10) with the standing upper-body set.

#          during RMB+LMB: mode=9 or 10; after the get-off: partner_seat_aim=end; who=local; k=0; reason=watch; ...;
#          aims>=1; fires>=1 (also partner_action_events=local ... fire_count increments)
#          act=0x6e in every sample while seated (the aim never breaks the seat), partner_ride=local_passenger stays on,
#          no new partner_ride=pass_camera; state=refused, no viewer_changed / uncertain=1 / board_uncertain /
#          crash_probe=av
#   host   partner_seat_aim=sample; who=local; k=0; act=0x6f; ... armed=0; ...; c3=1 (the driver keeps "no weapon")
#          partner_seat_aim=sample; who=body1; k=1; ...; seat=2|3 while the seat flow holds body 1: equip / hand / mode
#          say whether body 1 still holds the remote's gun while DM-seated (design A of the research note)
#          partner_action_state; ... flags=0x1|0x3; ...; act=110 while the remote passenger aims / fires (the signal
#          design A would use; missing means the sender drops aim in act 0x6E)
