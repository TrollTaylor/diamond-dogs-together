# Africa, seed africa-jeep (Masa Village, veh_lv_0000 = 25608 at about (-654.32, 0.43, 878.61), yaw 2.664 rad: forward
# f = (0.460, -0.888), the driver's side L = (-0.888, -0.460)). The host drives (goto_vehicle jeep = the driver's door);
# the guest boards from the passenger side (beside its boot spot) so it takes back seat 3, with no driver between it
# and a target ahead-right. A guard is warped 12 m ahead of the jeep and 1.5 m to the passenger side, facing the jeep
# (the host stands 17 m ahead facing back for spawn_enemy here; debug_soldier_warp=1, notice restricted).
#
# Expected (the guest is the passenger, the host drives):
#   guest  partner_seat_aim=on; mission=30020; read_only=1; writes=0; calls=0
#          partner_seat_aim=sample; who=local; k=0; act=0x6e; ... armed=1; c2=0; c3=0 once the seat loop runs
#          during the RMB hold: upper=0x02 and mode=7 (posture=0: no back-seat posture in UpdateAttackType);
#          during RMB+LMB: mode=9 or 10; after the get-off partner_seat_aim=end; who=local; ...; aims>=1; fires>=1
#          aim_dir=refused; reason=ride while seated (the 0.13.6 RideGate), never reason=convention
#          the kill: world_lua=event=req; rid=..; ent=.. (REQ_OUTCOME), the host's event=commit; ...; actor=guest;
#   host   partner_seat_aim=sample; who=local; k=0; act=0x6f; ... armed=0 (the driver keeps "no weapon")
#          partner_seat_aim=sample; who=body1; k=1; ...; seat=3: equip / hand / mode say whether body 1 still holds
#          the remote's gun while DM-seated (E9's question); partner_action_state; ... flags=0x1|0x3; ...; act=110
#          while the remote passenger aims / fires (the signal the partner gun hold uses)
# Frames: seat-aim-guest-NN (the passenger's own view, gun raised?), seat-fire-guest-NN (the muzzle flash, the guard),
#   seat-aim-host-NN (the driver's view of the partner body while the remote aims), seat-drive-fire-guest-NN.
