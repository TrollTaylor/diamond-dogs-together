# neutral placements (no unwindowed drain), the placement yaw check, the windowed teleport, the look at its source (D3)
# and aim parity (the aim-target mirror, partner_native_aimpt: instance 1's network aim slot Q+0x10[1] gets a point
# 100 m along the remote's look, so the partner's gun aims where the remote aims and the aim-turn predicate 0x10A0AB0
# stops cycling act 12/15).
# Run (coordinator only, hidden worker):
#   A: pwsh -File tools/worker/Invoke-WorkerScenario.ps1 -ScenarioPath tools/worker/scenarios/partner-native-facing.txt -PartnerProfile native -NativeStage gun -BuildProfile research
#      (the gun stage emits partner_native_aimpt=look; face-aim-off is the in-session baseline: "guest debug aimpt off",

# Lab saves, noon, 30010. "Viewer" = the role filming its partner (body 1); captures.jsonl holds the viewer's state.json.
# First part: the host moves and the guest films (face-*); second part: the guest moves and the host films (g-face-*).
# Pass criteria (mechanical, on the viewer role):
#  every face-* (the guest films the host's partner) and g-face-* (the host films the guest's) capture: |heading_error_deg| < 10.
#  aim captures (face-aim*, face-crouch-aim, g-face-aim) after their first 600 ms: < 5 % of ring ticks with
#    |face_err_cdeg| > 1000; ring act 12 never unless the remote shows it (body.remote_act); native.look.err_mdeg < 1000
#    while native.look.remote_cdeg is not null. Run B: native.look.src "installed", src_hits_s > 0 while the viewer's
#    partner aims; the log has look_src=installed; site=0xff29fc. Run A: look.src "off".
#  face-place-viewer-aims (the guest holds RMB and films its partner while the host teleports: that partner is placed):
#    no body act 11 in the guest's capture ring (the placement ran with a neutral pad: the viewer's held RMB never
#    reached block 1's job; the ring holds ~1 s, so also check native.facing.neutral_windows growth and the log lines),
#    native.defer.per_s.unwindowed_native 0, the guest's log has partner_input=neutral; on=1 and never
#    partner_input=disarmed; reason=place under the native drive; partner_recon=placed; ok=1; yaw_err_mdeg
#    within 10000 (or a partner_recon=place_yaw_fix line before it).
#  native.facing.contests <= 2 per run, native.fallbacks 0, native.facing.mode never "contested" in face-* captures.
#  no ring act 25/26 caused by a governor write (25/26 only within 1.5 s after a partner_recon=place / snap line).
#  native.recon.snaps 0 outside placements; partner_recon=face_start / face_end lines for face-pivot-*, face-reposed.
#  both games close and the saves match (the worker's own checks).
# Aim parity (the viewer's native.aim; the source role's own aim in the same captures.jsonl line: roles.<source>.native.aim
#   aim_yaw0_cdeg / aim_pitch0_cdeg; the act-12 rule: the predicate tests rel_yaw1_cdeg = (0.5 - r60_1) * 18000, > 8000 turns):
#  face-aim-off (the mirror off, the old behaviour): aim.state "off", q10_1_mm constant (the world origin), pred1 1 and
#    rel_yaw1_cdeg beyond +-8000 at every ring act 12 start (r60_1 in the ring), the act 12/15 cycle the remote never shows.
#  face-aim, face-aim-held, face-aim-cam, face-aimturn*-settled, face-aim-strafe, face-aim-walk, face-crouch-aim*, g-face-aim*
#    after their first 300 ms: aim.state "ok", aim.refused 0, aim.writes growing, aim.overwritten 0 (else report it:
#    something else writes the slot offline), aim.src "look", aim.path1 "cam"; aim.slot "ours" (q10_1_mm == written_mm
#    +-1 mm; target_mm leads written_mm by one tick while moving); aimpt_err_mm (aim point 1 - written_mm) < 500; |wrap(aim_yaw1_cdeg - source aim_yaw0_cdeg)| <= 500 and |aim_pitch1_cdeg - aim_pitch0_cdeg| <= 500
#    on >= 95 % of captures (the remote's camera parallax: about atan(0.6 m / distance of its own aim point));
#    pred1 0 unless the remote's act is 12/15 (body.remote_act); ring act 12/15 only where the remote shows it;
#    |face_err_cdeg| <= 500 on >= 95 % of ring ticks after 600 ms (stand and crouch).
#  face-aimturn-pivot / face-aimturn-l-pivot (the qualified +-1500 mouse stimulus while aiming): the remote turns (act
#    12, its body 72..87 degrees); the partner shows act 12 within 2 captures and settles within 5 degrees of the remote
#    (the -settled frames); body 1's stock rifle turns only beyond 80 degrees of aim (a sighted remote at 27): a
#    turn of 27..80 degrees twists the partner instead (an open item, -LabSetting partner_native_face=aim covers it).
#  face-aim-strafe / face-aim-walk: body act = the remote's aim-walk class (13/14), yaw error <= 5 degrees.
#  the restore: aim.restores is 1 after face-aim-off (the A/B) and grows afterwards only when the native drive left; the
#    log has partner_aim=installed at native entry and once more after face-aim-off, and never partner_aim=fault,
#    refused or restore_dropped.
