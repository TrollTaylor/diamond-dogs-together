# separate 600 ms holds so the previous direction expires before the next.

# own expiry, so this sequence preserves Shift/W and explicitly lets A/D expire.

# - run-before-shift: source and partner standing run, native active;
# - shift-added / shift-steady: source actually sprints; body sprint class/rate
#   catches up, steady speed ratio 0.95..1.05, no unexpected place/snap/runaway;
# - left/right/forward: source Shift remains held; partner does not get stuck
#   in ordinary run after a turn; no native fallback or mission latch;
# - stop-settled: body follows the idle source, error <500 mm and no idle runaway.
# Inspect command_accepted times and source frames for expiry or stalled capture
# I/O. A late or expired input section is inconclusive and must be repeated.
# Relatch is bounded (300 ms debounce and 1500 ms retry gap, four/10 s); it may correctly remain unused if
