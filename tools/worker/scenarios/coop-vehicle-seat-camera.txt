# Design 8.25 (docs/vehicles-companions-design.md; docs/native-puppet.md "Passenger camera"): the back-seat
# passenger's aim camera, the A/B of the passenger camera's ignore-collision handle. The host drives the africa-jeep
# (veh_lv_0000 = 25608) and stays still; the guest rides back seat 3 (goto_vehicle jeep right: the right side), then
# back seat 2 (goto_vehicle jeep: the driver's, left side). In each seat the lab lever "passcam" switches the
# guest's passenger camera live: connect (0.14.4: the handle for the whole ride), off (never connected: the stock
# collision), aim (connected, dropped while the guest aims and 0.6 s after). Each variant: the camera turned across
# the jeep (enemy_cam_turn 0 5: the seated body's facing, 5 deg down), RMB held, three single LMB shots, release.
# Then, with aim, the camera turned out of the passenger's own side (enemy_cam_turn 180) and along the jeep (90)
# before an aim: what the stock aim range does there (design 8.22: +-90 deg around the body's facing).
# partner_pass_camera_trace=1 logs the guest's camera every 100 ms while it aims (and 4 s after), else every 1 s:
#   partner_ride=pass_camera; state=trace; seat=..; mode=..; aim=..; gun=..; f3c0=..; h=<handle held>; cam_cm=<camera
#   minus body>; body_cm; byaw_cdeg; ang_mrad=<CAM+0x268..0x274>; rot=<CAM+0x90 x1000>; tgt_cm=<the aim target minus
#   the camera>; apt_cm=<the gun's aim point minus the camera>; r5c; r60; f204; d38; cmode
# Expected (lab): guest partner_ride=pass_camera; state=mode; mode=connect|off|aim; source=lever; with aim
#   state=aim; event=drop at each aim and event=restore 0.6 s after it ended; debug_menu=passcam; ok=1.
# Frames (look at them): s3-seated, s3{c,o,a}-aim / -shot1..3 / -after / -after2, s3a-out, s3a-along; the same for
