# Design 8.25 (docs/vehicles-companions-design.md; docs/native-puppet.md "Passenger camera"): the back-seat
# passenger's aim camera at the default mode aim (partner_pass_camera unnamed: the jeep's ignore-collision handle kept,
# and the shot guard holding the camera's look angles and rotation through each shot). africa-jeep (veh_lv_0000 =
# 25608). The host drives and stays still; the guest rides back seat 3 (goto_vehicle jeep right), then back seat 2
# (goto_vehicle jeep); then the guest drives and the host rides back seat 3. Each passenger aims the way a player does
# right after boarding (RMB, the camera where boarding left it: across the jeep), fires three single shots, releases.
# Earlier versions of this file: 4f1a072f (v1: connect / off / drop A/B with the trace: the shot's pull to the sky is

# 43e5b981 (the rotation hold: seat 3's view held through three shots).
# partner_pass_camera_trace=1 logs the camera every 100 ms while aiming (and 4 s after), else every 1 s.
# Expected (lab): each passenger's partner_ride=pass_camera; state=mode; mode=aim; source=key; state=guard; event=open
#   at the first shot, event=close; writes=..; max_pull_mrad=..; rot_writes=.. after the last; no state=aim; event=drop.
