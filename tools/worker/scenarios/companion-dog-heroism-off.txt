# Control for the heroism give-back (docs/vehicles-companions-design.md 8.16): the session is NOT host-owned, so the
# guest's D-Dog is the guest's own (world_companion_guard.lua's C.applies() false, as with the key off) and its death must
# keep the stock penalty. The host runs without companion_host_owned (the shipped default); the guest names the key only
# so its native guard is installed and the lab lever companion_lab kill_own reaches its own dog (the native kill flag
# through a lab op with arm 0): without the host's key the peer agreement never forms, the guest keeps its own buddy
# (no seeds), the legacy mirror holds it at the host dog's pose, and the give-back never runs. Seed africa-jeep (each
# copy has its own D-Dog). The first version of this control (the guest's C4, run a7f00043, both keys off) never reached
# the dog and downed the host through the friendly hit, so the kill is the lab lever's.
#   pwsh -File tools/worker/Invoke-WorkerScenario.ps1 -ScenarioPath tools/worker/scenarios/companion-dog-heroism-off.txt
#        -PartnerProfile native -NativeStage gun -BuildProfile research -SaveSeed africa-jeep
# Expected: host dog_guard=off reason=key_off; guest dog_guard=installed; guest kill_own ready=true; guest obs Dead
# id=9728; the guest's hero readback 30 lower (bond_raw 20 lower, dead_bit=1, applies=0, deaths=0), the host's
# unchanged; "D-Dog Near Death [Heroism -30]" on the guest's screen. NEVER: event=dog_hero, event=dog_restore.

labsetting nametag=1
labsetting coop_hud=compact

host debug clear_enemies 100
host run godmode 1
guest run godmode 1

wait 3000
