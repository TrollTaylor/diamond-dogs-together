# Preparing-member teardown

Workspace **0.10.18** adds DYNAMITE's preparing-member disconnect step before session close. It is compiled only, not installed or executed. Playable two-player co-op remains unverified.

Pinned upstream `c90f252f8200765f66c005d6bf4357fda0c0d98e`, `moddata/standalone/TppMain.lua`, calls `SessionDisconnectPreparingMembers` followed by `CloseSession`. The adapter now performs that order once after original mission termination returns. It requires both Lua functions and prior native authorization. A failed preparing call stops the sequence. After a returned preparing call, native code rechecks the creation thread, tracked session, main-session and network-owner pointers, types, state, mission and close bodies before permitting close. This prevents a missing main session from being manufactured by the wrapper's lazy getter. Returning from either call is not proof of asynchronous completion.

The existing preparing wrapper at RVA `0xA1B580` calls the primary session interface slot `+0x78`, mapped to `0x313490`. That method sets session byte `+0xE3` to 1. It then reads an existing auxiliary singleton through `0x7DE090` (global `0x2BEFDD0`) and, if its child at `+0x58` exists, calls `0x80D2E0` to set bit 4 in child byte `+0x30`. The original game update consumes those requests; the mod does not directly delete members or free objects.

The auxiliary owner must match constructor table `0x221BE58`. An optional child must carry the constructor's embedded interface table `0x222F1F8` at `+0x18` and its own address at `+0x28`. Its factory, publication, update and destruction are traced. Twelve complete body hashes gate this addition; existing complete main-session/close contracts also remain required. The owner and child pointer are reread after hashing. These reads do not provide an atomic lifetime lease or rule out address reuse.

[Static mapping and exact executable fingerprint](https://github.com/TrollTaylor/diamond-dogs-together/blob/archive/research-2026-10-23/docs/evidence/preparing-disconnect-contract-2026-09-10.json). This service is separate from the FOB parameter-service branch of full `CloseSession`. Version 0.10.19 adds its [wrapper mission-branch adaptation](full-close.md), retaining the native service implementation, which remains unmapped. A missing auxiliary singleton, unexpected child or changed code refuses the teardown sequence. No fallback close or reconnect is silently attempted. Failed sequences remain one-shot; rule-restoration retries only restore owned gameplay rules.
