# Installed script bridge trial

This page records the historical 0.5.0 pass-through trial. The current 0.6.0 loader additionally supports the [exact-source bootstrap](script-bootstrap.md), whose script replacement and execution receipt have now been observed live.

2026-09-09. Loader 0.5.0 installs the script bridge after the successful DirectInput8Create return and the existing exact executable fingerprint, loader location, image bounds and DLL pin checks. The bridge additionally checks all 36 bytes of the observed loader function at RVA `0x1A178E0`. MinHook provides the trampoline. [Boundary and fixtures](script-load-bridge.md).

Observation requires `mgs-coop/script-observe.enabled` beside the game containing exactly the 11 ASCII bytes `observe-v1` followed by LF. No marker or other content leaves the hook inactive. The installed development marker enables only pass-through observation: the selector always returns false. This is not a general loose-file loader. The hook keeps no Lua state or script buffer, makes no additional Lua calls and never replaces scripts or mounts archives.

Logs record bounded, sanitized 240-byte name prefixes for entries 1–32, 256, 1024 and 4096, and independently sample the same return counts. Entries and returns are not paired across recursion or threads. Each logged return describes an original parser result; unlogged calls are not an error census. Logging and policy storage live until process exit with the pinned DLL; there is no live uninstall. Remove or change the marker only to affect the next launch. [Source](../native/game_script_observer.cpp).
