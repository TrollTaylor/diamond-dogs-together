# Custom archive loading experiment

**Trial 6 verified live archive opening, script path resolution and execution. Player packages are not yet selected.**

Loader 0.7.0 adds an opt-in `archive-v1\n` marker mode. It checks the accepted executable and the complete creation function at RVA `0x48E20`, then checks a fixed-size, fingerprinted local archive. It attempts one mount after successful DirectInput creation, on the existing startup thread. The unique mount name, archive pathname and returned game handle have process lifetime. The fingerprinting read handle is closed before the engine opens the archive. This leaves a small interval between verification and engine open; this development experiment assumes no other process edits its owned archive. No unmount helper or I/O-count setter is called.

The native adapter is project-authored, informed by tpp-mod's pinned GPLv3 symbols and custom-pack call contract and the independently observed [natural call](https://github.com/TrollTaylor/diamond-dogs-together/blob/archive/research-2026-10-23/docs/archive-mount-observation.md). It does not copy the upstream implementation. Dynamite-derived player definitions retain their separate full terms in the local game directory.

The local archive at `build/four-player-runtime-20260909d/mgs-coop-player-runtime.dat` contains the four previously checked player package files and a project-authored `MgsCoopArchiveProbe.lua`. All five files pass exact-path and byte-hash extraction checks. Its size is 2,420,736 bytes; SHA-256 is `711def02f258f6ca42a63ca2374fdf342a306adb1ba29fe31f7e6df94b1830e5`. [Bundle report](https://github.com/TrollTaylor/diamond-dogs-together/blob/archive/research-2026-10-23/docs/evidence/player-runtime-bundle-2026-09-09/bundle-with-probe.json). Actor packages are not added to any mission list.

The exact-source Tpp.lua patch has separate immutable caches for ordinary bootstrap and mounted-archive bootstrap. Only a type-1 handle with a nonnull stream enables the second variant. That fragment requests the probe script and logs whether the request returned; the probe itself emits a different execution receipt. A returned request is deliberately not counted as script execution. Lua `dofile` provides an additional protected direct-read diagnostic. Both loading forms are used in the game's [published startup script](https://github.com/eur0pa/MGSV.LUA/blob/master/LUA/start.lua); current runtime behavior is established by the trials, not inferred from that older source.

## Validation and remaining work

All 14 native suites pass. The two bootstrap variants pass 23 source-preservation/refusal/cache checks and 800 concurrent selections; the fixture's printed 400 count describes only its original loop. Lua 5.1 fixtures exercise successful and failing library requests, successful and failing direct reads, and missing APIs. The generated asset round trip covers four FOX2 definitions, two original MTAR files and all five archive files.

These checks do not demonstrate loaded player packages or four actors. With script resolution now established, package selection must append only the controller FPK and verify live allocation and resource sufficiency before remote control, transport and campaign work are enabled. Every campaign entry remains unsupported.
