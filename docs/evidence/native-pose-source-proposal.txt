# Proposed source deltas; not a patch and not integrated
Exact component and callback qualification is still required. The pure gate
only closes the check-then-enter race among participating wrappers.

partner_defer.cpp WrapBatch:
- TryRead gate before calling g_batch_orig, for EVERY main/foreign/nested entry.
- Keep ticket through g_batch_orig and its existing __finally.
- EndRead after the native join returns, before Drain. Never upgrade shared.
- Busy foreign reader: wait/retry actual TryRead within a private copied-save
  deadline. Timeout invokes the owned supervisor failure path. Do not call
  original, drain, decrement an unowned ticket or drop exclusive ownership.
- nested_writer on same thread: fail private experiment without waiting or
  original. A joined foreign thread cannot be safely allowed through.
- This bounded-failure strategy qualifies isolation, not production liveness.

partner_input_hook.cpp RunJobWindow / DrainCall:
- JobResult replaces the ambiguous bool.
- nativePoseRequired comes from retained accepted pose lease BEFORE ReadArm.
  Missing Arm never removes this requirement.
- Every unarmed/InBatch/type/block/SafePre/source/C0/UI failure uses suppressed
  when required. DrainCall counts suppressed separately and never forwards.
- TryWrite only after current two-body, source/lifetime, actual installed-hook
  qualification; nonwaiting exclusive CAS must win before BeginWindow.
- All legacy sibling pad/camera/local-id windows must participate or refuse
  when an owned pose writer is present. Do not run body0 callbacks on swapped
  fields and do not let nested windows independently close the outer sequence.
- Capture existing typed C0 token and separately qualified UI four-field token
  before any SafePre, rate/mag/slot/aim/hud native calls.
- One outer POD-compatible __try/__finally covers Pre/job/probes/Post:
  1) withdraw Quiet/detour/look once;
  2) attempt SafePost/prefix-restoration under independent SEH;
  3) attempt typed UI restoration under independent SEH;
  4) attempt C0 restoration under independent SEH;
  5) EndWindow exactly once;
  6) EndWrite ONLY if all typed cleanup and close receipts succeeded.
  Existing GuardedCall abnormal Post/End must become one-owner cleanup or a
  prefix-restored/closed receipt, not a second unaccounted close.
- On cleanup failure retain poisoned exclusive ticket/lease, controls and
  typed failure reason; owned private-process supervisor must terminate.
- g_job_fn is global; a nested call must be refused before assigning it.
  Otherwise a refused nested invocation can replace the outer job function.

global shared C0 and UI:
- Typed natural updater 11F6760 must take shared before ANY original work and
  release in finally, not merely gate the later promotion call 11F7210.
- If an independent direct promotion hook is needed, it uses the same gate.
  Reentrant same-writer owner refuses/skips with private failure, never waits.
- Known UI natural vt0 FE8E10 needs participation; complete hint consumer
  census is still missing. Installing just this one entry must not set
  allParticipantsInstalled=true.
- ABI/hook/trampoline/new call sites require exact full-code gate review
  separately. The pure Gate does not qualify patching those addresses.

shutdown / native actor teardown:
- StopNewWriters; preserve retained owner/generation/epoch and existing C0/UI
  tokens through cleanup, independent of ReadArm shutting down.
- Do not reset gate or destroy/reconfigure actor components while a writer is
  active. Native scene replacement/destruction must be a participating reader
  or have separately proven same-owner nonconcurrent lifecycle.
- A token's actor replacement can refuse old-pointer cleanup, but then it
  cannot release corrupted prior shared objects or imply successful restore.

Tests staged, not built or run in this task: pure actual atomic interleaving,
existing-reader/writer races, same-owner nested refusal, generation ownership,
shutdown retained cleanup, consumed ticket and post-fault poisoned lifetime.
No claim of native hook coverage, native job liveness or body1 activation.
